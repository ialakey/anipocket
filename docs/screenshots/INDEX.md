# Screenshots

All captures come from a real run of the app on an Android 16 (API 36) emulator
at 1080×2400, in the dark theme, against the live catalog (AnimeGO). Nothing here
is a mockup.

For the repository they are downscaled to a 1600 px long side. Flat UI screens are
stored as 256-colour PNG; the six screens dominated by artwork are JPEG (quality
92), which is both smaller and closer to the original than a palette would be.

How they were taken — see [development.md](../en/development.md#driving-the-app-on-an-emulator).
